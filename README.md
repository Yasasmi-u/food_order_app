# 🍽️ foodie — Premium Online Food Ordering System

A high-end, full-stack Online Food Ordering System built with **Spring Boot** and **React TypeScript**. This project features a state-of-the-art **Glassmorphism UI**, dynamic animations, and a secure JWT-based authentication system.

---

## ✨ Design Highlights
- **Premium Aesthetics**: A sleek "Light Background / Glass Card" system with vibrant amber accents.
- **Typography**: Powered by the professional **Plus Jakarta Sans** typeface.
- **Glassmorphism**: Translucent panels with backdrop-blur effects and soft shadows.
- **Dynamic Interactions**: Micro-animations and hover effects for a premium "app-like" experience.

---

## 📌 Tech Stack

### Backend
- **Java 17** & **Spring Boot 3.2.5**

- **Lombok** for clean code

### Frontend
- React 18 (TypeScript)
- React Router DOM
- Axios
- Tailwind CSS
- Vite

## 🗄️ Database Setup

1. Create a database named `food_app` in your MySQL environment:
   ```sql
   CREATE DATABASE food_app;
   ```
2. The tables are automatically generated by Hibernate on first run (`ddl-auto: update`).
3. (Optional) Run the provided `db_seed.sql` to populate initial categories and food items.

## ⚙️ Backend Setup (`/backend/backend`)

1. Open in IntelliJ IDEA or your preferred Java IDE.
2. Ensure your `application.properties` matches your local MySQL settings:
   ```properties
   spring.datasource.url=jdbc:mysql://localhost:3306/food_app
   spring.datasource.username=root
   spring.datasource.password=
   ```
3. Run the application via `BackendApplication.java` or use:
   ```bash
   ./gradlew bootRun
   ```
   *Server starts on `http://localhost:8080`*

## 🌐 Frontend Setup (`/frontend/frontend`)

1. Open the `frontend/frontend` folder in VS Code

2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Access the app at **`http://localhost:5173`** (or `http://localhost:5174`).

## 🔐 API Endpoints

### Auth
| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| POST | `/auth/signup` | Register user | **None** (Public) |
| POST | `/auth/login` | Login & get token | **None** (Public) |

### Food Items
| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| GET | `/foods` | Get all food items | **Yes** (JWT) |
| POST | `/foods` | Add food item | **Yes** (Admin) |
| GET | `/foods/category/{id}` | Get by category | **Yes** (JWT) |
| DELETE | `/foods/{id}` | Delete food item | **Yes** (Admin) |

### Categories
| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| GET | `/categories` | Get all categories | **Yes** (JWT) |
| POST | `/categories` | Add category | **Yes** (Admin) |

### Cart
| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| GET | `/cart/{userId}` | View cart | **Yes** (JWT) |
| POST | `/cart/add` | Add to cart | **Yes** (JWT) |
| DELETE | `/cart/remove/{id}` | Remove item | **Yes** (JWT) |
| DELETE | `/cart/clear/{id}` | Clear cart | **Yes** (JWT) |

### Orders & Payments
| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| POST | `/orders/place/{id}` | Place order | **Yes** (JWT) |
| GET | `/orders/{id}` | Get user orders | **Yes** (JWT) |
| POST | `/payments/{id}` | Make payment | **Yes** (JWT) |
